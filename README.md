DESCRIPTION: 
This project was completed as part of BCIS 566 - Business Analytics II course at New Mexico State University during Spring 2026.
The objective of this analysis is to features that predict income using machine learning techniques. 
This project demonstrates data preprocessing, exploratory data analysis, feature selection, and classification modeling to generate insights from
1994 Census Data https://archive.ics.uci.edu/dataset/2/adult.

FOLDERS INCLUDED:
-DATA: Stores raw dataset
-FIGURES: Contains all generated visualizations

FILES INCLUDED:
Dominguez_Semester_Project.ipynb: A Jupyter Notebook that performs data loading, cleaning, processing, machine learing methods, and plotting.
Dominguez_Report: A written file reporting the findings of classification models employed.

SYSTEM REQUIREMENTS:
- Python 3.x
- Anaconda
- Jupyter Notebook
- pip (Python package installer)

HOW TO SETUP AND RUN:
1. Ensure Python 3.13.0 (version 3.x or higher) is installed on your system.
2. Install required Python libraries: Open a terminal or command prompt and run the following command:
    pip install pandas numpy matplotlib seaborn
3. Running the Script: Navigate to the directory containing "Dominguez_Semester_Project.ipynb"
4. Using a terminal or command prompt and execute the following command:
    jupyter notebook
5. You will be directed to a new web browser window. Click on the "Dominguez_Semester_Project.ipynb" file. 
6. On the tool bar, per each juptyer file click Run > Run All Cells
NOTE: Ensure all data files listed above are in the same directory as the script or update the script with the correct
file path.

EXPECTED OUTPUT:
The notebook will clean datasets, perform classification models, report results, and provide visualizations.

TROUBLESHOOTING:
- If the script fails to execute, check that all required packages are installed correctly and Python is updated
to the latest version. Also check that you executed the notebooks in the respective order.
- Verify the path to all datasets is correct if the script cannot find the file.
- Ensure all data files are in the same directory as the script or update the script with the correct file path.
